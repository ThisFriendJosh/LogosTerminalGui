# Classic theme fonts

Unmodified font files from the supplied `fonts and styles.zip` package.
Each family retains its accompanying SIL Open Font License 1.1 and copyright
notice. Jost's license is `OFL.txt`; other licenses are beside their font files
under `themes/`.

| Themes | Preferred family |
| --- | --- |
| Classic Standard, Light, Dark | Jost |
| Classic Alchemist | IM Fell English, with Cinzel available as a fallback |
| Classic Lovecraft | IM Fell English |
| Classic DOS | VT323 |
| Classic Matrix | Share Tech Mono |

The host registers these files privately for its running process on Windows
and through application fonts on Linux/Fontconfig. No system font installation,
downloads or extra Python packages are required. Native fallback fonts remain
available on platforms without application-font registration.

The theme format currently uses one ordered family list for the workspace.
The HTML source's separate body/display roles are represented by a suitable
reading family in each classic conversion. Font files remain unchanged.
